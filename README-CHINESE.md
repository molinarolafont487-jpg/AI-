# 大成智改AI商学院官网

## 项目简介

这是一个完整的、专业的AI商学院官网项目，包含完整的前端代码和详细的部署文档。

## 技术栈

- Next.js 14
- React 18
- TypeScript 5
- Tailwind CSS 3
- Three.js（3D粒子动画）
- Framer Motion

## 项目特点

- ✅ 20+个专业React组件
- ✅ 9个首页核心区块
- ✅ 3500+行专业代码
- ✅ Three.js 3D粒子动画
- ✅ 完全响应式设计
- ✅ SEO优化配置

## 快速开始

### 本地开发

```bash
cd website
npm install
npm run dev
```

访问 http://localhost:3000

### 部署到Vercel

1. 推送代码到GitHub
2. 访问 https://vercel.com/new
3. 导入仓库
4. **重要**: Root Directory 设置为 `website`
5. 点击 Deploy
