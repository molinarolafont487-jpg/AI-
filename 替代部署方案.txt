🎯 Vercel CLI 部署方案（推荐）

你可以直接使用Vercel CLI部署，跳过GitHub：

1. 打开终端，执行：

cd /Users/yanlyubo/Desktop/大成智改商学院/website
npx vercel

2. 按提示操作：
   - Set up and deploy? Y
   - Which scope? 选择你的账号
   - Link to existing project? N
   - What's your project's name? dacheng-ai-academy
   - In which directory is your code located? ./
   - Want to override settings? N

3. 完成！会自动部署并给你URL
